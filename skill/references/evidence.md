# 证据库：每条规则为什么存在

adhd-md 不是审美偏好合集。每条规则都能说出它降低的是哪一种 ADHD 相关成本。这个文件是规则的证据索引 —— 做取舍、解释「为什么这样改」、或想改动某条规则时读。

详细的市场扫描与研究综述在仓库的 `docs/adhd-research.md`。这里是给 skill 执行时用的压缩版。

- [一、机制 → 规则总表](#一机制--规则总表)
- [二、逐组说明](#二逐组说明)
- [三、调研后明确不采纳](#三调研后明确不采纳)
- [四、出处速查](#四出处速查)

**证据分级**：

| 标记 | 含义 |
|---|---|
| 机制 | 有 ADHD 认知机制研究支持，但没测过「这条排版规则本身」 |
| 直接 | 有直接测过该类文本处理/排版的研究 |
| 标准 | W3C 认知无障碍官方指导明确要求 |
| 产品 | 多个 ADHD 友好产品的共同模式，研究证据弱或没有 |
| 未采纳 | 市场流行但证据不支持，列在这里防止以后改回去 |

## 一、机制 → 规则总表

| 机制 | 关键证据 | 规则 |
|---|---|---|
| 工作记忆容量有限 | WM 缺陷 d=0.43–1.06（Martinussen 2005）；组块约 4 个（Cowan 2001） | P1/P4/S3/W1/W4/L1/L5 |
| 结论优先降低启动成本 | 认知负荷理论；COGA 4.4.5「段落目的放开头」；走神与理解 r=−0.21 | S5/H1/H2/W7 |
| 任务拆解与单一动作 | COGA 4.4.9 每条指令单独成步；Goblin Tools/Llama Life 产品模式 | L3/A7/A8 |
| 时间感知差 | 时间感知 g=0.688；内部时钟偏快（PMID 34923055、38145491） | H4/A2/N7 |
| 延迟厌恶、需要即时反馈 | 双通道模型（Sonuga-Barke 2003）；奖赏通路（Volkow 2009） | 复选框/A7/A1/A3 |
| 启动困难 | Barkley 1997；执行功能缺陷 | A1/A4/A5 |
| 走神后重新定位 | COGA 4.2.4 当前步/剩余步；走神荟萃 | N1/N7/T7 |
| 多模态与降噪 | COGA 4.4.5/4.4.8；阅读模式产品 | T6/T8/N4/M 组 |

## 二、逐组说明

### S 组 · 骨架

| 规则 | 依据 | 级别 |
|---|---|---|
| S1/S2 标题层级稳定 | 可预测结构降低导航成本；COGA 4.3.3 | 标准 |
| S3 标题之间正文有上限 | 组块容量 4±1；COGA 4.3.5 Break Media into Chunks | 机制 |
| S4 标题写结论 | 结论式标题让目录成为「答案索引」，不看正文就能决定去哪 | 机制 |
| S5 结论块前置 | COGA 4.4.5「段落目的放开头」的文档级推广；走神窗缩短 | 标准 |
| S6 按文档类型定骨架 | 参考文档要跳读、教程要照做 —— 不同任务不同导航需求 | 产品 |
| S7 超长文件拆分 | 长内容加重时间盲与定位成本 | 机制 |
| S8 每节开头交代本节解决什么 | COGA 4.4.5 的分节版 | 标准 |

### H 组 · 首屏

| 规则 | 依据 | 级别 |
|---|---|---|
| H1/H2 前 15 行结论与 TL;DR | COGA 4.4.8 Summary of Long Documents；走神荟萃 r=−0.21 | 标准 |
| H3 首屏写读者收益 | 奖赏通路异常：先说「能得到什么」，别让读者自己推导 | 机制 |
| H4 首屏给时间/篇幅预估 | 时间感知 g=0.688；Llama Life「总清单时长/预计完成时间」、Goblin Estimator | 直接 |

H4 在 2026-08 调研后从 `deep` 提到 `standard`：时间预估是 ADHD 场景最便宜的启动辅助之一，且不破坏任何文档类型。

### P/L/W 组 · 分块、列表、句子

| 规则 | 依据 | 级别 |
|---|---|---|
| P1 段落 ≤3 句且 ≤80 词/160 字 | COGA 4.4.5 对短段落的定义与要求 | 标准 |
| P2 一段一主题 | 多主题段落要求读者在主题间切换，消耗执行控制 | 机制 |
| L3/L6/L7 有序步骤、分组、完整句 | COGA 4.4.9 Separate Each Instruction；组块 4±1 | 标准 |
| W1/W8/W9 短句、单从句、正面陈述 | 工作记忆容量；COGA 4.4.3 Avoid Double Negatives or Nested Clauses | 标准 |
| W2 主动语态 | COGA 4.4.2 Use a Simple Tense and Voice | 标准 |
| W4 消灭回扫指令 | 「如上所述」要求工作记忆清空重载，是 ADHD 场景放弃阅读的高发点 | 机制 |
| W5 术语首现解释 | 未知术语占工作记忆，解释前移等于预训练 | 机制 |
| W7 第二人称 + 现在时 + 具体动词 | 个性化原则（Mayer）；COGA 4.4.1 清晰用词 | 机制 |

### A 组 · 行动性

| 规则 | 依据 | 级别 |
|---|---|---|
| A1 可执行章节结尾给下一步 | 启动困难：明确动词与对象省掉「接下来呢」的推导 | 机制 |
| A2 步骤给时间预估 | 时间感知 g=0.688；Llama Life timeboxing | 直接 |
| A3 多选项给默认推荐 | 决策本身消耗执行功能；默认值降低选择成本 | 机制 |
| A4 命令可复制、无 `$` 前缀 | 复制粘贴是零启动动作，剥提示符消除一步手工编辑 | 机制 |
| A5 只做一件事入口 | 任务拆解产品（Goblin）与「小胜利」原则 | 产品 |
| A6 决策点给判断依据 | 把判断依据外置，不依赖读者记忆文档上下文 | 机制 |
| **A7 每步给预期输出或验证方法** | COGA 4.5.10 Provide Feedback；教程卡住的头号原因是「不知道这样算不算成功」 | 标准 |
| **A8 一步只做一个动作** | COGA 4.4.9 每条指令单独成步；Goblin/Llama Life 单一动作模式 | 标准 |

### N 组 · 导航

| 规则 | 依据 | 级别 |
|---|---|---|
| N1 TOC | 长文档的重新定位入口；COGA 4.3.6 | 标准 |
| N2 链接文本有意义 | 「点击这里」不给信息气味，扫读时是死链接 | 机制 |
| N4 可选内容折叠 | 渐进披露，给不需要的人省视线 | 产品 |
| **N7 多步流程标注进度** | COGA 4.2.4 Make Each Step Clear：走神回来能定位「第 X 步，共 N 步」 | 标准 |

### T 组 · 排版

| 规则 | 依据 | 级别 |
|---|---|---|
| T2/T3/T5 稀疏加粗、语义标记、统一警告 | 视觉锚点要稀疏才有信号；COGA 4.4.8 关键词加粗 | 机制 |
| T6 默认零 emoji | 屏幕阅读器逐字念、跨平台字形不稳；X1 反模式 | 产品 |
| T7 有序列表真实递增序号 | 口头引用「第 3 步」需要稳定序号；配合 N7 进度 | 机制 |
| T8 除 details/br 不用 HTML | 裸 HTML 会破坏部分宿主的渲染与可移植性 | 机制 |

### M 组 · 去 AI 味

| 规则 | 依据 |
|---|---|
| M1–M14 | 每一种 AI 套路都是一次具体的工作记忆税：翻案腔先装载再卸掉误解；预告式冒号把一句话说两遍；黑话要求先翻译。详见 `rules.md` 的逐条成本表 |

### X 组 · 反模式

| 反模式 | 依据 |
|---|---|
| X1 emoji 汤 | 产品调研确认 emoji 是 ADHD 产品的常见装饰（Llama Life、Tiimo 都有），但那些是**主动选择的个性化**，不是文档锚点；文档场景锚点密度一高就失效 |
| X5/X2/X3/X6/X7/X8 | 过度优化把「阅读成本」换成「信息损失 + 新噪音」；X4 是铁律 |

## 三、调研后明确不采纳

| 做法 | 证据 | 结论 |
|---|---|---|
| Bionic Reading 式词首加粗 | Snell 2024；Beelders 2025；Možina 等 2025 均无收益或更慢 | 不采纳。视觉锚点必须是稀疏语义锚点 |
| BeeLine 式颜色渐变 | 独立证据不足；且 Markdown 无法表达颜色 | 不采纳。属站点主题决策，不属文档格式 |
| 文字转语音、游戏化训练 | 不在 Markdown 结构层 | 不越界。宿主/阅读器能力 |
| emoji 锚点 | 见 X1 | 不采纳 |
| 身体双倍/社交问责 | 实时人际机制 | 无法由静态文档提供；用复选框与进度标注做降级替代 |
