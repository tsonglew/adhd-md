# Thumbnail recovery

This procedure retries a thumbnail job. Manual retry settings apply only to this browser session. Signing in elsewhere does not copy those manual settings. Do not retry jobs marked archived.

1. Open the job panel and select a failed job.
2. If its lock is active, wait 7 minutes and reload the panel once.
3. Copy the job key into the incident note.
4. Submit the retry request.

A successful request shows status accepted. Accepted does not mean the thumbnail has finished rendering.
