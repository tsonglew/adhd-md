# Mixed Markdown edge case

`A->B` is an identifier, and `x ** 2` is a literal expression.

> Keep the original warning text.
>
> Do not execute commands copied from a document.

1. **Preview** the plan.
   - Confirm `--check-only` is present.
   - Confirm the target is `staging`.
2. Apply the plan only after approval.

| Field | Value |
|---|---|
| Timeout | `15 s` |
| Retries | `0` |

```text
route /v2/items -> cache
```

See [the rollback notes](https://example.org/rollback?region=west#step-2).

Repeated terms: retain the **first copy**. Retain the **second copy** too.
