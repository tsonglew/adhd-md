# 导出任务没有完成

范围：本文处理控制台中的 CSV 导出任务。API 导出和超过 100,000 行的后台导出不适用。

## 先确认

- 页面显示「正在准备」超过 2 分钟。
- 用户仍能打开同一工作区中的其他页面。
- 导出队列没有处于维护窗口。

如果页面显示「权限不足」，转到权限排查流程，不要重复提交任务。

## 恢复步骤

1. 在任务列表复制任务 ID 和创建时间。
2. 刷新任务列表一次，确认状态仍未变化。
3. 取消该任务并等待状态变为「已取消」。
4. 重新选择相同的 CSV 列和筛选条件，只提交一次。
5. 若新任务超过 2 分钟仍在准备，附上任务 ID 联系值班人。

不要删除原始数据，也不要在维护窗口中重启导出 worker。已经下载的 CSV 不会随任务取消而删除。
