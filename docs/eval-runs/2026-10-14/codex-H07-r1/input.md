# Local export archive

The archive stores completed exports for 14 days. It is available only to workspace owners and does not include files that failed before upload.

The archive is separate from the recycle bin. Deleting an export from the archive does not delete the source records.

## Download an export

1. Open **Workspace settings → Exports**.
2. Select a completed export from the list.
3. Check the date and row count before downloading the ZIP file.
4. Keep the ZIP in an approved project folder; it may contain customer data.

## Limits

- Exports larger than 2 GB are split into numbered ZIP files.
- A link expires 30 minutes after it is created.
- Workspace guests cannot view the archive.
- If the archive is empty, check the selected workspace before requesting a new export.
