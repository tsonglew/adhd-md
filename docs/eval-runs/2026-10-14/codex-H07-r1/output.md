# Local export archive

The archive keeps completed exports for 14 days. Only workspace owners can access it. Files that failed before upload are excluded.

The archive is separate from the recycle bin. Deleting an archived export leaves the source records intact.

## Download and store an export

1. Open **Workspace settings → Exports**.
2. Select a completed export from the list.
3. Check the date and row count before downloading the ZIP file.
4. Store the ZIP in an approved project folder because it may contain customer data.

## Export size, link expiry, and access limits

- Exports larger than 2 GB are split into numbered ZIP files.
- Each link expires 30 minutes after creation.
- Workspace guests cannot view the archive.
- If the archive is empty, check the selected workspace before requesting a new export.
