# CSV 导出未完成时，先确认条件再重试

范围：仅处理控制台中的 CSV 导出任务。API 导出和超过 100,000 行的后台导出不适用。满足先决条件后按七步恢复，重试后仍超时就联系值班人。

## 以下条件全部满足后再恢复

- 页面显示「正在准备」超过 2 分钟。
- 用户仍能打开同一工作区中的其他页面。
- 导出队列不在维护窗口内。

如果页面显示「权限不足」，转到权限排查流程，不要重复提交任务。

## 按七步取消旧任务并重新提交

1. 第一步，共七步：在任务列表复制任务 ID 和创建时间。
2. 第二步，共七步：刷新任务列表一次。确认状态仍未变化后，再继续。
3. 第三步，共七步：取消该任务。
4. 第四步，共七步：等待任务状态变为「已取消」，再继续。
5. 第五步，共七步：重新选择与原任务相同的 CSV 列和筛选条件。
6. 第六步，共七步：只提交一次。
7. 第七步，共七步：若新任务超过 2 分钟仍显示「正在准备」，附上任务 ID 联系值班人。

不要删除原始数据，也不要在维护窗口中重启导出 worker。已经下载的 CSV 不会随任务取消而删除。
