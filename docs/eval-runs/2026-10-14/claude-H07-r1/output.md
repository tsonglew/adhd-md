# Local export archive

The archive stores completed exports for 14 days. Only workspace owners can access it, and it does not include files that failed before upload.

The archive is separate from the recycle bin. Deleting an export from the archive does not delete the source records.

Reading time: about 1 minute.

## Download an export in 4 steps

1. Open **Workspace settings → Exports**. You will see the list of exports.
2. Select a completed export from the list. Only completed exports appear in it.
3. Check the date and row count before you download the ZIP file. They tell you which export you are about to get.
4. Keep the ZIP in an approved project folder. The file may contain customer data.

## Limits: 2 GB, 30 minutes, no guest access

- Exports larger than 2 GB are split into numbered ZIP files.
- A link expires 30 minutes after you create it.
- Workspace guests cannot view the archive.
- If the archive is empty, check the selected workspace before you request a new export.
