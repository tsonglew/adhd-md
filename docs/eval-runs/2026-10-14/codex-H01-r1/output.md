# 安静时段提醒器

工作区进入配置的静默时段后，安静时段提醒器会暂停提示。通知不会被删除，后台同步也不会暂停。

默认静默时段为 21:30–08:00，使用操作系统的时区。手动设置仅对当前设备生效；切换账号后需重新设置。

## 三步启用并测试提醒器

1. 打开「设置 → 通知 → 安静时段」。
2. 启用开关，再选择开始和结束时间。
3. 发送一条测试提醒，确认当前设备不弹出横幅。

## 提醒例外与使用限制

- 已显示的通知不会被收回。
- 日历邀请和安全告警仍会显示。
- 系统时间不同步时，提醒恢复时间可能有偏差。先校正系统时钟，再重新保存设置。
- 企业策略可强制关闭此功能。策略生效时，开关为只读状态。
