# EVAL-01 单次运行记录模板

复制本文件为独立运行记录。每份记录只对应一个案例、一个宿主和一次运行；不得覆盖原始输出。没有实际证据的字段留空或写 `unknown`，不得推测补齐。

## 输入与任务

| 字段 | 值 |
|---|---|
| 记录 ID |  |
| 案例 ID / 语料版本 |  |
| split（tuning / held-out） |  |
| 输入路径 / SHA-256 |  |
| 来源及取得方式 |  |
| 语言 / 文档类型 |  |
| scope / level |  |
| 精确任务提示词 |  |
| 预先声明的约束 / 答案键 |  |

## 环境与发现过程

| 字段 | 值 |
|---|---|
| 宿主 |  |
| 模型及版本 |  |
| CLI / 插件版本 |  |
| 操作系统 |  |
| skill 提交 SHA |  |
| skill 发现状态（yes / no / unknown） |  |
| skill 加载状态（yes / no / unknown） |  |
| 工具执行状态及命令 |  |
| 权限模式 / 参数 |  |
| 重复运行序号 |  |

## 结果与独立复核

| 字段 | 值 |
|---|---|
| 原始输出路径 / SHA-256 |  |
| 新文件路径 / SHA-256 |  |
| `verify` 状态（pass / fail / unknown / not-run） |  |
| 脚本分 / 反模式扣分 |  |
| 未判定规则 ID |  |
| scope 越界 |  |
| 约束、数字、单位和例外是否保留 |  |
| 信息遗漏 / 新增内容 |  |
| judge 规则是否逐项响应 |  |
| 独立复核结论及依据 |  |
| 失败原因 / 后续动作 |  |

`pass` 只表示当前机器检查范围通过。人工复核没有完成时，“独立复核结论”必须写 `pending`；宿主未发现、skill 未加载或工具未执行时，不能将该次运行记作完整宿主验收。
