# 首轮阅读任务试验方案

状态：方案草稿，尚未招募或收集参与者数据。须在开始前确认任务材料、匿名记录位置和参与同意文本。

## 目的和边界

首轮只发现信息查找、约束理解、步骤执行和阅读器操作中的可用性问题。它不诊断 ADHD，不评估治疗效果，也不能证明改写对 ADHD 人群普遍有效。5–8 人的便利样本只用于发现问题，不用于统计显著性或总体效果推断。

招募成年人自愿参与。记录不询问诊断、病史、药物或其他健康信息。参与者可以跳过任何问题、暂停或退出；退出不会带来任何不利后果。

## 同意说明

开始前向参与者展示并确认以下说明：

> 我了解这是一项阅读材料和阅读器的可用性试验，不是能力、诊断或治疗评估。参与自愿，我可以跳过问题、暂停或随时退出。我同意研究者用匿名编号记录任务答案、完成时间和阅读负担评分，并将去标识化的汇总结果用于改进 adhd-md。试验不录音、不录像、不记录屏幕，也不收集姓名或健康信息。我可以在结果汇总前要求删除自己的记录。

保存一项明确的同意状态和日期即可，不在结果文件中写参与者姓名或联系方式。若要公开逐例记录或超出项目改进范围使用结果，需另行取得明确同意；首轮默认只分享汇总数据。

## 试验设计

分别观察排版改写和阅读器界面两个因素，避免一次改变两者后无法判断原因：

| 条件 | 内容 | 呈现方式 |
|---|---|---|
| A | 原始文档 | 静态页面 |
| B | ADHD 友好改写 | 静态页面 |
| C | 原始文档 | 阅读器 |
| D | ADHD 友好改写 | 阅读器 |

每位参与者完成四个难度和主题相近、但内容不同的短任务，每种条件各一次。每个任务使用独立答案键；同一参与者不重复阅读同一篇材料。通过轮换材料与条件的对应关系，并平衡先后顺序，降低熟悉内容和练习效应。顺序表应在招募前冻结，不能按中途结果临时调整。

每个任务先给参与者一个真实目标，例如找出默认值、适用条件、执行步骤或失败后的处理方式。问题与答案键在试验前确定。答案键同时列出不可遗漏的限制、例外、单位和先决条件，便于记录遗漏而不是只统计是否答对。

## 测量项目

对每个任务记录：

- 答案正确项 / 总项，以及遗漏的必要条件、例外、单位或步骤
- 从展示材料到提交答案的秒数；暂停时间单独备注
- 参与者自评阅读负担，1 表示很轻，7 表示很重
- 是否需要回看、使用目录或调整字号行距；只记操作次数，不录屏
- 参与者主动指出的困惑和失败原因，使用匿名编号并避免补记身份信息

完成四个任务后再问总体偏好和最想修复的一处问题。不要询问诊断或要求参与者解释其注意力特征。

## 执行步骤

1. 说明目的、隐私范围、退出方式并取得同意。
2. 用不计入结果的练习题说明操作方式，确认参与者会使用计时器和答题表。
3. 按预先冻结的顺序展示四个条件；研究者只可重复任务说明，不提示答案。
4. 每个任务后记录答案、耗时、遗漏项和阅读负担评分。
5. 结束后询问总体偏好，说明本试验不评价个人能力，并提供删除匿名记录的联系途径。
6. 复核匿名数据，删除意外写入的个人信息，再计算各条件的逐例结果和中位数。

## 报告方式

报告逐例的任务正确率、遗漏、耗时和负担评分，同时说明未完成任务、退出、材料顺序与异常情况。按“原始 / 改写”和“静态 / 阅读器”分别展示，不合成一个效果分。样本较小，只描述观察到的模式和失败案例，不声称因果、临床效果或对所有用户有效。
